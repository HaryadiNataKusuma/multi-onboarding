1. Pengenalan Program

Apa itu Travel Product Onboarding?

Travel Product Onboarding adalah sistem yang dirancang khusus untuk membantu Anda mengelola data produk travel insurance dengan mudah dan efisien. Sistem ini memungkinkan Anda untuk:

  • Mengelola data produk asuransi travel
  • Mengatur region (wilayah) dan negara
  • Mengelola aturan produk dan komisi
  • Mengatur template dan addon (tambahan) produk
  • Melacak riwayat perubahan data

Fitur Utama Sistem

✨ Fitur Unggulan:
  • Draft System: Simpan data sementara sebelum menyimpan ke database
  • Excel Upload: Unggah data dalam jumlah banyak sekaligus
  • Excel Template: Download template untuk memudahkan input data
  • Filter & Search: Cari dan filter data dengan mudah
  • Edit & Update: Ubah data yang sudah tersimpan
  • History Tracking: Lihat riwayat perubahan data

Siapa yang Bisa Menggunakan Sistem Ini?

Sistem ini dirancang untuk semua pengguna, baik yang sudah berpengalaman maupun pemula. Interface yang sederhana dan intuitif memudahkan siapa saja untuk menggunakan sistem ini tanpa perlu pelatihan khusus.

2. Memahami Konsep DRAFT dan RESULT

Apa itu DRAFT?

DRAFT adalah data sementara yang Anda buat atau edit, tetapi belum disimpan ke database. Data DRAFT hanya tersimpan di memori browser Anda dan akan hilang jika Anda menutup halaman tanpa menyimpannya.

Karakteristik DRAFT:

  • ✅ Data tersimpan sementara di browser
  • ✅ Bisa di-edit atau dihapus kapan saja
  • ✅ Belum tersimpan ke database
  • ⚠️ Akan hilang jika browser ditutup tanpa konfirmasi
  • 📝 Biasanya digunakan untuk menyiapkan data sebelum disimpan permanen

Apa itu RESULT?

RESULT adalah data yang sudah tersimpan di database. Data ini permanen dan bisa dilihat, di-edit, atau dihapus kapan saja.

Karakteristik RESULT:

  • 💾 Data tersimpan permanen di database
  • ✅ Bisa dilihat, di-edit, atau dihapus
  • 🔄 Perubahan langsung tersimpan ke database
  • 📊 Data ini yang digunakan oleh sistem lain
  • 🔍 Bisa difilter dan dicari

Kapan Menggunakan DRAFT vs RESULT?

Kegiatan Gunakan DRAFT Gunakan RESULT
Membuat data baru ✅ Ya - untuk persiapan ✅ Ya - setelah konfirmasi
Mengedit data ✅ Ya - untuk data baru ✅ Ya - untuk data yang sudah ada
Menghapus data ✅ Ya - sebelum konfirmasi ✅ Ya - langsung dari database
Melihat data ✅ Ya - preview ✅ Ya - data final
⚠️ Peringatan Penting:

Pastikan Anda mengkonfirmasi data DRAFT sebelum menutup halaman, karena data DRAFT yang belum dikonfirmasi akan hilang.

3. Langkah-Langkah Penggunaan

Langkah 1: Pilih Insurance Code

1 Pilih Insurance Code dari dropdown di bagian atas halaman

Insurance Code adalah kode perusahaan asuransi yang akan Anda kelola datanya. Pilih dari dropdown "List Asuransi" sebelum mulai bekerja dengan data.

Langkah 2: Pilih Section yang Ingin Dikelola

2 Scroll ke bawah dan pilih section yang ingin Anda kelola

Ada 7 section utama yang bisa Anda kelola:

  • Insurance - Data perusahaan asuransi
  • Regions - Data wilayah dan negara
  • Products - Data produk asuransi
  • Product Rules - Aturan produk
  • Templates - Template produk
  • Commissions - Data komisi
  • Addons - Data addon (tambahan) produk

Langkah 3: Input Data Baru

3 Isi form dengan data yang diperlukan

Setiap section memiliki form input yang berbeda. Isi semua field yang wajib (ditandai dengan tanda *).

Opsi Input Data:

  • Input Manual: Isi form satu per satu
  • Upload Excel: Klik tombol "Upload Excel" untuk mengunggah banyak data sekaligus
  • Download Template: Klik "Download Template Excel" untuk mendapatkan format Excel yang benar

Langkah 4: Simpan sebagai DRAFT

4 Klik tombol "Save Draft" atau "Tambah" untuk menyimpan sebagai DRAFT

Data akan tersimpan sebagai DRAFT dan bisa Anda lihat di bagian "Draft Data". Anda bisa mengedit atau menghapus data DRAFT sebelum mengkonfirmasinya.

Langkah 5: Review Data DRAFT

5 Klik "Tampilkan Draft Data" untuk melihat semua data DRAFT

Periksa kembali data yang sudah Anda input. Pastikan semua data sudah benar sebelum dikonfirmasi.

Langkah 6: Konfirmasi Data ke Database

6 Klik tombol "Konfirmasi Data (DB)" untuk menyimpan ke database

Setelah dikonfirmasi, data akan tersimpan permanen di database dan tidak bisa dihapus dengan mudah.

⚠️ Perhatian:

Setelah data dikonfirmasi ke database, data tersebut akan menjadi data RESULT dan akan digunakan oleh sistem lain. Pastikan data sudah benar sebelum mengkonfirmasi.

Langkah 7: Melihat Data RESULT

7 Klik tombol "RESULT" untuk melihat data yang sudah tersimpan di database

Di sini Anda bisa melihat, mengedit, atau memfilter data yang sudah tersimpan permanen.

Langkah 8: Edit atau Hapus Data

8 Klik tombol "Edit" untuk mengubah data atau "Delete" untuk menghapus

Untuk data DRAFT, perubahan langsung tersimpan. Untuk data RESULT, perubahan langsung tersimpan ke database.

4. Penjelasan Setiap Section

1. Insurance Section

Fungsi: Mengelola data perusahaan asuransi

Field Utama:

  • Code: Kode unik perusahaan asuransi
  • Name: Nama perusahaan asuransi
  • Is Active: Status aktif/tidak aktif

Cara Menggunakan:

  1. Isi form dengan data perusahaan asuransi
  2. Klik "Tambah" untuk menyimpan sebagai DRAFT
  3. Klik "Tampilkan Draft Data" untuk melihat DRAFT
  4. Klik "Konfirmasi Data (DB)" untuk menyimpan ke database

2. Regions Section

Fungsi: Mengelola data wilayah dan negara

Field Utama:

  • Name: Nama wilayah (contoh: DAMAI WORLDWIDE)
  • Type: Tipe wilayah (WHITELIST/BLACKLIST)
  • Country IDs: Daftar ID negara yang termasuk dalam wilayah

Fitur Khusus:

  • Tombol "Select Countries" untuk memilih negara dari daftar lengkap
  • Fitur "Exclude Countries" untuk mengecualikan negara dari wilayah lain

Cara Menggunakan:

  1. Isi nama dan tipe wilayah
  2. Klik "Select Countries" untuk memilih negara
  3. Pilih negara yang diinginkan dari modal yang muncul
  4. Klik "Confirm" untuk menyimpan pilihan
  5. Klik "Tambah" untuk menyimpan sebagai DRAFT
  6. Konfirmasi ke database jika sudah benar

3. Products Section

Fungsi: Mengelola data produk asuransi travel

Field Utama:

  • Product Name: Nama produk
  • Type: Tipe produk (INDIVIDUAL/COUPLE/FAMILY)
  • Region ID: Wilayah produk
  • Min/Max Adult/Child: Batas jumlah peserta
  • Summary: Ringkasan produk
  • Insurance Detail: Detail asuransi
  • Addons: Tambahan produk (opsional)

Fitur Khusus:

  • Auto-generate Product Code berdasarkan input
  • Tombol "Addons" untuk menambahkan addon ke produk
  • Filter berdasarkan Type dan Region

Cara Menggunakan:

  1. Pastikan sudah memilih Insurance Code
  2. Isi semua field wajib (bertanda *)
  3. Klik "Addons" jika ingin menambahkan addon
  4. Klik "Tambah" untuk menyimpan sebagai DRAFT
  5. Review dan konfirmasi ke database

4. Product Rules Section

Fungsi: Mengelola aturan produk (premium, durasi, dll)

Field Utama:

  • Product Code: Kode produk
  • Premium Type: Tipe premium (DAILY/ANNUAL/PER_EXTRA_SEVEN_DAYS)
  • Start Days / End Days: Rentang hari
  • Base Premium Value: Nilai premium dasar
  • Rules: Aturan khusus (JSON format)

Cara Menggunakan:

  1. Pilih Product Code dari dropdown
  2. Isi field premium type dan durasi
  3. Isi nilai premium
  4. Simpan sebagai DRAFT atau langsung ke database

5. Templates Section

Fungsi: Mengelola template HTML untuk produk

Field Utama:

  • Product Code: Kode produk
  • Template HTML: Kode HTML template

Fitur Khusus:

  • Editor HTML untuk mengedit template
  • Preview template sebelum menyimpan

6. Commissions Section

Fungsi: Mengelola data komisi untuk produk

Field Utama:

  • Product Code: Kode produk
  • Commission Type: Tipe komisi
  • Commission Value: Nilai komisi

Cara Menggunakan:

  1. Pilih Product Code
  2. Isi tipe dan nilai komisi
  3. Simpan sebagai DRAFT atau langsung ke database

7. Addons Section

Fungsi: Mengelola detail aturan addon (tambahan) produk

Field Utama:

  • Addon Rule ID: ID aturan addon
  • Start/End Condition: Kondisi mulai dan akhir
  • Value Type: Tipe nilai (FIXED/PERCENTAGE)
  • Value: Nilai addon
  • Duration Rule Type: Tipe durasi aturan
  • Min/Max Adult & Max Age: Batas usia dan jumlah

Fitur Khusus:

  • Upload Excel untuk input banyak data sekaligus
  • Download template Excel
  • Filter berdasarkan Addon Name dan Product Name

Cara Menggunakan:

  1. Input Manual: Isi form dan klik "Tambah"
  2. Upload Excel:
    • Klik "Download Template Excel" untuk mendapatkan format
    • Isi template dengan data Anda
    • Klik "Upload Excel" dan pilih file
    • Data akan masuk ke DRAFT
  3. Review data DRAFT
  4. Konfirmasi ke database

8. Histories Section

Fungsi: Melihat riwayat perubahan data

Informasi yang Ditampilkan:

  • Tanggal dan waktu perubahan
  • User yang melakukan perubahan
  • Tipe perubahan (CREATE/UPDATE/DELETE)
  • Data sebelum dan sesudah perubahan

Cara Menggunakan:

  1. Klik "RESULT" untuk melihat riwayat
  2. Data akan ditampilkan dalam tabel
  3. Gunakan filter jika perlu

Tips & Trik

Tips Umum

  • ✅ Selalu pilih Insurance Code sebelum mulai bekerja
  • ✅ Gunakan DRAFT untuk menyiapkan data sebelum menyimpan permanen
  • ✅ Review data DRAFT sebelum mengkonfirmasi
  • ✅ Gunakan Excel upload untuk input data dalam jumlah banyak
  • ✅ Download template Excel untuk memastikan format benar
  • ✅ Gunakan filter untuk mencari data dengan cepat

Tips Upload Excel

  • Pastikan format Excel sesuai dengan template
  • Jangan mengubah header (baris pertama) pada template
  • Isi semua field wajib
  • Pastikan tipe data sesuai (angka untuk angka, teks untuk teks)
  • Hapus baris kosong sebelum upload

Tips Edit Data

  • Untuk data DRAFT: Edit langsung dari tabel DRAFT
  • Untuk data RESULT: Klik tombol "Edit" di tabel RESULT
  • Perubahan data RESULT langsung tersimpan ke database
  • Gunakan tombol "Cancel" untuk membatalkan edit

Tips Filter Data

  • Gunakan filter dropdown untuk menyaring data
  • Klik "Clear Filter" untuk menghapus semua filter
  • Filter hanya berlaku untuk data RESULT

Pertanyaan yang Sering Diajukan (FAQ)

Q: Apa yang terjadi jika saya menutup browser sebelum mengkonfirmasi DRAFT?

A: Data DRAFT akan hilang. Pastikan Anda mengkonfirmasi data DRAFT sebelum menutup browser.

Q: Bisakah saya mengedit data yang sudah dikonfirmasi ke database?

A: Ya, Anda bisa mengedit data RESULT dengan klik tombol "Edit" di tabel RESULT.

Q: Bagaimana cara menghapus data yang sudah dikonfirmasi?

A: Untuk data RESULT, klik tombol "Delete" di tabel RESULT. Perhatian: Hapus data dengan hati-hati karena akan langsung terhapus dari database.

Q: Format Excel seperti apa yang harus saya gunakan?

A: Download template Excel dari setiap section untuk mendapatkan format yang benar. Jangan mengubah header atau format template.

Q: Apa perbedaan antara DRAFT dan RESULT?

A: DRAFT adalah data sementara yang belum tersimpan ke database. RESULT adalah data yang sudah tersimpan permanen di database.

Q: Bagaimana cara melihat data yang sudah saya input?

A: Klik "Tampilkan Draft Data" untuk melihat DRAFT, atau klik "RESULT" untuk melihat data di database.

Kesimpulan

Sistem Travel Product Onboarding dirancang untuk memudahkan Anda dalam mengelola data produk asuransi travel. Dengan memahami konsep DRAFT dan RESULT, serta mengikuti langkah-langkah yang telah dijelaskan, Anda akan dapat menggunakan sistem ini dengan mudah dan efisien.

Ingat: Selalu review data DRAFT sebelum mengkonfirmasi ke database, karena data yang sudah dikonfirmasi akan langsung tersimpan permanen.

Jika Anda mengalami kesulitan atau memiliki pertanyaan, jangan ragu untuk menghubungi tim support.
